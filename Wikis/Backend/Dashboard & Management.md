# مستندات داشبورد و مدیریت پروژه (Dashboard & Management)

**تاریخ:** 2025-12-07
**پروژه:** TaskQuest

---

## مقدمه
این سند بخش‌های مدیریتی سیستم TaskQuest شامل داشبورد، مدیریت وظایف، پروژه‌ها و تیم‌ها را پوشش می‌دهد. این بخش‌ها در نسخه‌های 6 و 7 به سیستم اضافه شده‌اند تا هسته اصلی عملکردی برنامه را تشکیل دهند.

## معماری مشترک (BasePage)
تمام صفحات مدیریتی از یک کلاس پایه به نام `BasePage` ارث‌بری می‌کنند. این کلاس وظیفه مدیریت یکپارچه موارد زیر را بر عهده دارد:
1. **انکودینگ (Encoding):** تضمین نمایش صحیح متون فارسی با تنظیم `UTF-8` و فرهنگ `fa-IR`.
2. **احراز هویت:** بررسی وضعیت لاگین کاربر در `Page_Load` (هرچند در حال حاضر در خود صفحات نیز بررسی می‌شود، اما BasePage زیرساخت آن را فراهم می‌کند).
3. **متدهای کمکی:** مانند `SafeEncodePersianText` برای رفع مشکلات نمایش کاراکترهای خاص.

```csharp
public class BasePage : Page
{
    protected override void OnInit(EventArgs e)
    {
        Response.ContentEncoding = System.Text.Encoding.UTF8;
        Response.Charset = "UTF-8";
        // ... تنظیمات فرهنگ
        base.OnInit(e);
    }
    // ...
}
```

## 1. داشبورد (Dashboard.aspx)
صفحه اصلی پس از ورود کاربر است.
- **مسیر:** `p:\TaskQuest\TaskQuest\TaskQuest\Dashboard.aspx`
- **ویژگی‌ها:**
  - نمایش پیام خوش‌آمدگویی.
  - نقطه شروع برای دسترسی به سایر بخش‌ها.
  - بررسی وضعیت Session کاربر برای جلوگیری از دسترسی غیرمجاز.

## 2. مدیریت وظایف (Tasks.aspx)
صفحه اصلی برای تعریف و پیگیری کارها.
- **ویژگی‌ها:**
  - لیست وظایف با قابلیت نمایش وضعیت (در انتظار، در حال انجام، تکمیل شده).
  - دکمه "افزودن وظیفه جدید" که یک مودال (Modal) را باز می‌کند.
  - استفاده از `SqlParameter` برای امنیت در برابر SQL Injection.
  - فیکس مشکل انکودینگ برای ورودی‌های فارسی در عنوان و توضیحات وظایف.

## 3. مدیریت پروژه‌ها (Projects.aspx)
صفحه تعریف پروژه‌های کلان که وظایف زیرمجموعه آن‌ها قرار می‌گیرند.
- **ویژگی‌ها:**
  - نمایش لیست پروژه‌های فعال.
  - فرم ایجاد پروژه جدید با تعیین نام، توضیحات و تاریخ پایان.
  - ارتباط با دیتابیس برای ذخیره و بازیابی اطلاعات پروژه.

## 4. مدیریت تیم‌ها (Teams.aspx)
صفحه مدیریت اعضای تیم و همکاری.
- **ویژگی‌ها:**
  - نمایش لیست اعضای تیم.
  - قابلیت دعوت از اعضای جدید (در فازهای بعدی توسعه تکمیل می‌شود).
  - مدیریت دسترسی‌ها و نقش‌ها.

## نکات فنی و تغییرات اخیر
### رفع مشکل انکودینگ (Encoding Fixes)
در نسخه 7، مشکل نمایش کاراکترهای فارسی (مانند "تکمیل پروفایل" که به صورت "ØªÚ©Ù..." نمایش داده می‌شد) به طور کامل برطرف شد.
- **راهکار:** استفاده از `BasePage` و متد `SafeEncodePersianText` برای تبدیل بایت‌های ناخوانا به رشته UTF-8 صحیح قبل از نمایش در کنترل‌های `Label`.
- **مثال:**
```csharp
lblWelcome.Text = SafeEncodePersianText("کاربر گرامی خوش آمدید");
```

### رفع خطاهای کامپایل (Compilation Fixes)
مشکلات مربوط به `CS0246` (عدم شناسایی `BasePage`) با اضافه کردن فایل `BasePage.cs` به فایل پروژه (`.csproj`) و اطمینان از وجود دستورات `using` مناسب برطرف گردید.

## ساختار دیتابیس مرتبط
این صفحات با جداول زیر در دیتابیس `TodoAppDB` در ارتباط هستند:
- **Tasks:** ذخیره وظایف (`Title`, `Description`, `Status`, `DueDate`, `UserID`).
- **Projects:** ذخیره پروژه‌ها (`ProjectName`, `Description`, `StartDate`, `EndDate`).
- **TeamMembers:** ارتباط کاربران با پروژه‌ها یا تیم‌ها.
